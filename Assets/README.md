# Portfolio assets

## Add photographs later

1. Put the original photo in `Assets/`.
2. Set the matching path in `Assets/images.js`, for example:

```js
portrait: 'Assets/dr-subayyal-ikram.jpg',
'pearl-one-tower': 'Assets/pearl-one-tower.jpg',
```

The portrait fits within the hero arch. Project images fill their matching cards. Empty entries retain the existing project photograph/render or illustrated portrait placeholder. Failed overrides leave the existing image in place.

## Included assets

- `images/brand/logo-transparent.png`: transparent logo edited with the built-in imagegen tool.
- `images/projects/`: 13 original-resolution company project images.
- `images/recitations/`: Al-Qamar, Muhammad and Ar-Rahman thumbnails.
- `icons/`: social/website SVG icons and their MIT license.

Source URLs, dimensions and editing prompts are recorded in the JSON files and `IMAGE_EDIT_NOTES.md` in this folder. Platform handles and URL spellings stay unchanged when switching languages.
